## 五、問題回答

### Q1：為什麼 people = "4" 需要轉換成 int 才能進行除法？

因為 `"4"` 是字串（str），不是數字，不能直接作為除法運算的除數。

使用 `int(people)` 可以將字串 `"4"` 轉換成整數 `4`，才能正確進行數學計算。

例如：
- `"4" + "1"` 的結果是 `"41"`，因為這是字串相連。
- `4 + 1` 的結果是 `5`，因為這是數值加法。

因此，在進行數學運算之前，需要先將資料轉換成正確的型別。

### Q2：如果先扣除折價券，再計算服務費，結果會有什麼不同？

原本的計算方式是先以原始餐費 1,200 元計算 10% 服務費：

- 原始餐費：1,200 元
- 服務費：1,200 × 10% = 120 元
- 折價券：100 元
- 應付總額：1,200 + 120 - 100 = 1,220 元
- 每人費用：1,220 ÷ 4 = 305 元

如果先扣除折價券再計算服務費：

- 折扣後餐費：1,200 - 100 = 1,100 元
- 服務費：1,100 × 10% = 110 元
- 應付總額：1,100 + 110 = 1,210 元
- 每人費用：1,210 ÷ 4 = 302.50 元

兩種方式的應付總額相差 10 元，每人費用相差 2.50 元。原因是先扣除折價券後，計算服務費的基準金額降低，因此服務費也會減少。
